# StudyBuddy AI v1.0.0

The first stable release of StudyBuddy AI — built solo over a 10-day sprint as the capstone for the AB Talks 60-Day Claude AI Challenge.

**Live app:** https://studybuddy-ai-sandy.vercel.app

## What it does

Paste any notes, article, or chapter and get an instant AI-generated summary, key takeaways, and a self-test multiple-choice quiz — powered by the Google Gemini API. No login, no account, no setup.

## Features

- ⚡ AI-generated summaries, key takeaways, and quizzes via Google Gemini
- 🧠 Instant, colorblind-safe quiz answer feedback
- 🕘 Local session history (save, reopen, delete) — no server-side storage of your data
- 📱 Fully responsive, desktop and mobile
- ♿ WCAG AA accessible — keyboard navigation, screen-reader support
- 🔒 Privacy-first — your text never touches a database

## Under the hood

Vanilla HTML/CSS/JS frontend, a single Vercel serverless function backend, and browser `localStorage` for history — deliberately no database, no auth. Full architecture, API spec, and data schema documented in the repo.

## Known limitations

Documented transparently in `TESTING.md`: no server-side rate limiting yet, hardcoded Gemini model name, no automated test suite. All three are scoped into the post-launch `30-day-growth-plan.md`.
